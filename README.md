# LIFEPAC Research

Public research index for LIFEPAC curriculum sample PDFs and contents outlines.

## What this repo contains

- Official public AOP/GLN sample PDF links
- Extracted table-of-contents outlines from those official samples
- Grade-by-grade outline text files
- Internet Archive library/borrow references where found

## What this repo does not contain

- Full paid curriculum workbooks
- Pirated PDFs
- Circumvention instructions

## Files

- `lifepac/pdf-links.md` — official sample links and archive references
- `lifepac/contents-outline.md` — full extracted contents outline for grades 1–12
- `lifepac/grades/` — smaller per-grade outline files
- `lifepac/data/contents-data.json` — extracted structured data

## Notes

The sample PDFs are public preview files hosted by AOP/GLN. The extracted contents are intended as a curriculum planning/index aid.
